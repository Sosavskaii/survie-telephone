# Survie sur téléphone : une IA et Wikipédia sans réseau

Plus de courant, plus d'antenne ? Avec ces 2 applis gratuites, ton téléphone garde une IA et une encyclopédie. **À installer maintenant** : tout se télécharge, le jour du blackout il sera trop tard.

## 1. PocketPal AI, une IA qui marche sans internet

Gratuite et open source (licence MIT) : [github.com/a-ghorbani/pocketpal-ai](https://github.com/a-ghorbani/pocketpal-ai)

- **iPhone** : cherche « PocketPal AI » dans l'App Store
- **Android** : cherche « PocketPal AI » dans le Play Store

Pas à pas :
1. Ouvre l'appli, va dans **Models**.
2. Télécharge un petit modèle (ceux de 1 à 3 Go marchent sur la plupart des téléphones récents).
3. Une fois téléchargé, active le mode avion et pose-lui une question : elle répond quand même.

## 2. Kiwix, Wikipédia dans ta poche

Gratuit et open source : [kiwix.org](https://kiwix.org)

- **iPhone** : « Kiwix » dans l'App Store
- **Android** : « Kiwix » dans le Play Store

Pas à pas :
1. Ouvre l'appli, va dans la bibliothèque.
2. Télécharge **Wikipédia en français** (il existe des versions légères sans images) et, si tu as la place, **WikiMed** pour la médecine.
3. Teste en mode avion.

## 3. Le courant

Une batterie externe chargée, rangée dans un tiroir. Et un petit chargeur solaire si tu veux aller plus loin.

## Pour l'ordi

La version ordinateur (IA locale + Wikipédia + guides de survie) : [Survival LLM](https://github.com/anonnerdfrenzy/survival-llm).
